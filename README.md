# Manchester-United-xG-Analysis
Analysing Manchester United's attacking efficiency across five Premier League seasons using xG, statistical analysis and predictive modelling in Python

Project Overview : 

This project investigates the correlation between expected goals and goals scored for Manchester United, from the 2020/21 season, to 2024/25.
I analyse the differences in attacking performance between seasons and under different managers, offering potential footballing reasons
for these variations.

Skills Demonstrated : 

- Python
- pandas
- NumPy
- Matplotlib
- Statistical analysis
- Linear regression
- Quadratic regression
- Data visualisation

Main findings :

- Solskjaer's united team demonstrated the highest level of clincality, scoring more goals per unit increase in expected goals than other managers.
- Finishing efficiency per match was most consistently high during the 2020/21 season
- Amorim had the largest variance in how expected goals influenced goals scored within this period
